# 书写形状

通过加强概念基础、候选开口钩子和深思熟虑的块级格式，将原始笔记、成绩单片段和研究堆积成结构化、连贯的文章草稿。

---

## 核心不变量

1. **输入不变性**：原材料文件严格只读；将文章整理成一个新的单独文档。
2. **严格的概念基础**：在任何后续段落依赖它之前，每个概念都必须有基础（作为预定义的读者先决条件或在较早的块中引入）。
3. **多开口选择**：在构建主体之前，始终呈现 2-3 个代表不同角度/主题的不同开口钩。
4. **有意的块格式**：正式证明每个块的格式合理（散文与列表、标注与内联、表格与文本、引用与释义）。
5. **增量持久性**：通过在每次写入之前重新读取实时磁盘，逐段追加和细化文章草稿文件。

---

## 架构和内容地图 (MOC)

```
[ Raw Notes / Fragment Pile (Read-Only) ] ──► [ Establish Reader Prerequisites ] ──► [ Select Opening Hook (2-3 Options) ] ──► [ Block-by-Block Construction ]
```

|决策区|权衡分析|规则|
|---|---|---|
| **散文与列表** |争论性流程与可扫描项目 |散文承载着论文；列表包含严格平行的项目 |
| **内联与标注** |主线连续性与旁白上下文|仅当内联破坏论文时才使用标注（`> [!NOTE]`）
| **表格与段落** |重复的结构化模式|超过 3 个项目具有匹配的键 $\rightarrow$ 表 |
| **引用与释义** |历史措辞与核心思想|当精确的措辞很重要时引用；为了清楚起见，解释一下|

## 分步程序 (TWI)

### 第 1 步：摄取桩和结算先决条件
- **行动**：端到端地阅读原始片段堆，并确定读者为文章带来了哪些基础知识。
- **要点**：在整个会议期间实时记录基础概念。
- **为什么**：防止文章依赖未引入的术语的认知差距。

### 第 2 步：草拟 2-3 名候选人空缺
- **行动**：以不同角度呈现 2-3 个不同的空缺并强制进行选择。
- **关键点**：所选择的空缺为选秀的其余部分设定了明确的合同。
- **内嵌清单**：
  - [ ] 未触及的原始堆
  - [ ] 已记录的先决条件
  - [ ] 同意打开并写入目标草稿文件

### 步骤 3：逐段增加草稿
- **行动**：询问“给定这个块，读者接下来需要什么？”，从堆中提取材料，并讨论块格式。
- **要点**：写入前重新读取文件并立即追加。
- **为什么**：逐步构图可确保无缝过渡并消除绒毛。

## 反合理化护栏

|诱人的合理化|约束规则|工程原理 |
|---|---|---|
| *“在一个大回合中一次性生成整篇文章。”* | **与用户逐块起草和辩论。** |单次生成生成通用散文并忽略用户语气偏好。 |
| *“在整形过程中直接编辑原始注释文件。”* | **原材料是只读的；写入单独的草稿。** |更改源代码堆会破坏未来文章所需的原始片段。 |
| *“在介绍基本概念之前使用术语。”* | **在依赖条款之前强制执行先决条件。** |不接地气的概念会疏远读者并削弱论证结构。 |
