＃ 不可触摸

将复杂的对话历史记录、锁定的架构决策、畅通的下一步操作以及验证证据压缩到一个独立的降价移交文档中，以供新的代理会话使用。

---

## 核心不变量

1. **外部临时存储**：将交接文档保存到操作系统临时目录（`/tmp/handoff-<timestamp>.md`）或指定的临时文件夹中——永远不会污染项目根存储库文件。
2. **上下文指针经济**：直接指向存储库工件、问题 URL、提交 SHA 和测试套件，而不是复制文本墙。
3. **建议技能路由**：显式声明“##建议技能”块，指示恢复代理应首先调用哪些专门技能。
4. **严格秘密编辑**：确保零凭证、令牌、API 密钥或私人身份验证标头泄漏到移交文件中。
5. **准确的下一个命令**：提供继续执行所需的准确命令行或下一个提示，而不会产生歧义。

---

## 架构和内容地图 (MOC)

```
[ Active Multi-Turn Session ] ──► [ Extract Invariants, Decisions & Blockers ] ──► [ Write `/tmp/handoff-*.md` ] ──► [ Output Resume Command ]
```

|部分|目的|示例内容 |
|---|---|---|
| **目标和范围** |这项举措取得了什么成果 |规格边界、用户需求|
| **决策和不变量** |建筑硬合同已敲定 |领域模型选择、ADR 指针 |
| **当前状态和差异** |确切的工作树状态 | Git 状态、修改的文件、通过测试 |
| **建议技能** |下一次会议需要的工具 | `[skills/implement-spec/SKILL.md](file:///...)` |
| **确切的下一步行动** |原子下一步|命令或任务边界主张|

---

## 分步程序 (TWI)

### 第 1 步：综合会话增量和决策
- **行动**：提取已解决的关键路径决策、已修改的活动文件以及未解决的问题。
- **要点**：检查所有决策是否与其主要 ADR 或规格相关。
- **为什么**：恢复代理需要选择背后的“原因”，而不需要重新提起已解决的讨论。

### 第 2 步：格式化移交文档并编辑机密
- **行动**：用目标、已完成的工作、活跃的阻碍因素、建议的技能和下一步行动来构建 Markdown 文档。
- **要点**：扫描文本以确保不包含私人令牌或环境机密。
- **内嵌清单**：
  - [ ] 保存在“/tmp/”中（例如“/tmp/handoff-2026-08-30.md”）
  - [ ] 明确列出建议的技能
  - [ ] 零秘密存在

### 第 3 步：发出恢复指令
- **操作**：向用户输出完整的完成摘要，其中包含移交文件的确切路径以及下一个代理如何摄取它。
- **为什么**：允许即时会话恢复而不会丢失上下文。

## 反合理化护栏

|诱人的合理化|约束规则|工程原理 |
|---|---|---|
| *“将移交直接写入项目存储库根目录。”* | **将切换保存到`/tmp/`或临时操作系统目录。** |临时会话转储会污染 git 历史记录并使存储库源树变得混乱。 |
| *“将完整文件内容粘贴到移交文档中。”* | **使用简洁的上下文指针和文件路径。** |粘贴整个文件会消耗恢复代理会话时的上下文预算。 |
| *“省略建议的技能并让下一个特工猜测。”* | **强制性“建议技能”部分。** |直接技能指导可防止恢复代理陷入通用工作流程。 |
