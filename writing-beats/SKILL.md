# 写作节拍

推动一个交互式的、选择你自己的冒险起草循环，其中每个节拍都会引入一个集中的叙事动作，尊重扎根的先决条件，并解锁可到达的后续路径。

---

## 核心不变量

1. **每回合一个节拍**：提出 2-3 个候选下一步动作，预览每个动作解锁的内容，并严格将每回合选定的一个节拍写入磁盘。
2. **动态可达性和基础**：只有当所有必需的概念都已经扎根时（无论是作为基线先决条件还是由先前的节拍引入），候选节拍才是可达的。
3. **禁止提前批量写入**：切勿提前写入未经批准的节拍；每个节拍必须在计算后续分支之前建立状态。
4. **保留作者修订**：在生成下一个候选文件以无缝合并用户编辑之前，始终从磁盘重新读取草稿文件。
5. **空堆的完整旅程**：当叙事旅程完成时，文章就结束了，而不是当堆中的每个原始片段都用完时。

## 分步程序 (TWI)

### 第 1 步：初始化接地矩阵和先决条件
- **行动**：吸收原始数据并与用户就观众所了解的概念达成一致。
- **要点**：跟踪会话内存中的基础概念的活动列表。
- **为什么**：确保读者在概念上可以访问每个候选分支。

### 第 2 步：制定候选下一个节拍
- **行动**：提供从一堆中抽取的 2-3 个候选节拍，明确说明：(1) 它需要什么概念，(2) 它基于什么新概念，(3) 它解锁了哪些方向。
- **内嵌清单**：
  - [ ] 可从当前接地组联系到的所有候选人
  - [ ] 每个候选人代表一个独特的叙事分支
  - [ ] 为用户预览解锁路径

### 步骤 3：附加选择的节拍并重新读取磁盘
- **操作**：将用户选择的节拍写入草稿文件，并在计算下一步之前重新读取整个草稿。
- **关键点**：如果用户要求回溯或重写较早的节拍，请就地编辑它并重新计算可用分支。
- **为什么**：为作者提供关于文章节奏和叙述语气的完整互动机构。

## 反合理化护栏

|诱人的合理化|约束规则|工程原理 |
|---|---|---|
| *“一次写 3 个节拍以加快起草速度。”* | **每回合准确写出 1 个节拍。** |批处理节拍消除了作者引导分支方向的能力。 |
| *“将所有剩余的原始片段强制放入草稿中。”* | **当旅程完成时结束；将多余的部分留在堆中。** |将未使用的片段强行放入草稿中会削弱清晰度并使叙述变得混乱。 |
| *“提供需要不落地概念的候选节拍。”* | **对所有候选人强制执行先决条件可达性。** |跳入没有根据的概念会让读者感到困惑并破坏论证的连续性。 |
