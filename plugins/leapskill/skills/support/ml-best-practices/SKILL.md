# 机器学习最佳实践

在探索性分析、特征工程、模型训练和统计性能验证中应用严格的机器学习工程标准。

## 核心原则

> **每个模型发现都必须以无泄漏分割、双模型基线和统计置信区间为基础。**

---

## 核心不变量

1. **严格的训练测试隔离**：在安装任何缩放器、编码器或转换器之前，始终将数据集划分为训练、验证和测试部分。
2. **强制性缺失值策略**：明确量化缺失值频率并记录保留、删除或估算缺失值的域理由。
3. **双模型基准**：永远不要孤立地依赖单一模型架构。根据幼稚的基线训练至少两个不同的候选家庭。
4. **相对于原始平均值的统计显着性**：报告关键评估指标（F1、AUC、RMSE）的 95% 引导置信区间，以验证统计分离。
5. **故事优先的笔记本结构**：每个代码执行单元都必须与分析性Markdown单元配对，解释观察到的模式、权衡和结论。

## 分步程序 (TWI)

### 第 1 步：探索性分析和异常检测
- **操作**：检查架构、计算汇总统计数据并使用散点图和直方图可视化目标分布。
- **关键点**：在建模之前检查目标列异常、极端异常值和无意义值。
- **为什么**：在损坏或未检测到的异常目标上训练模型会使实验设置无效。

### 步骤 2：监督建模（分类/回归）
- **行动**：在 scikit-learn 管道内应用专门适合训练数据的转换器；评估正则化以控制过度拟合。
- **关键点**：对于高基数名义特征，限制基数或使用具有折叠正则化的目标编码。
- **为什么**：在组合数据集上安装变换器会导致微妙的目标和方差泄漏。
- **内嵌清单**：
  - [ ] 按时间顺序（如果是时间顺序）或通过 StratifiedKFold（如果是分类）分割数据
  - [ ] 编码器和缩放器包裹在 Pipeline 内，仅安装在 X_train 上
  - [ ] 生成混淆矩阵、ROC 曲线或残差诊断图
  - [ ] 通过记录的理由处理缺失值

### 步骤 3：无监督聚类和时间序列预测
- **行动**：对于聚类，标准化特征并优化Silhouette Score；用于预测、测试平稳性和季节性。
- **关键点**：对于时间序列，验证未来信息不会泄漏到历史滞后特征中。
- **为什么**：轮廓优化可以防止任意簇计数选择；平稳性测试确定合适的模型族。

### 步骤 4：模型比较和 95% Bootstrap 置信区间
- **操作**：在相同的交叉验证折叠上对多个候选模型进行基准测试并计算引导程序置信区间。
- **关键点**：对关键子群体进行基于切片的误差分析，并编制操作权衡表。
- **原因**：对准确性的点估计通常会掩盖关键客户群的绩效下降。

## 反合理化护栏

|诱人的合理化|约束规则|工程原理 |
|---|---|---|
| *“分割之前的标准缩放是无害的。”* | **将缩放器严格安装在训练折叠上。** |缩放器计算数据集范围内的统计数据，这些统计数据会导致微妙的分布泄漏。 |
| *“准确度为 94%，因此分类器已准备就绪。”* | **始终检查 PR-AUC、F1 和混淆矩阵。** |在不平衡类别上，94% 的准确率可能比天真的多数类别猜测还要差。 |
| *“我们不需要基线，因为 XGBoost 更优越。”* | **始终首先建立朴素和线性基线。** |朴素基线证明了模型复杂性的合理性并揭示了真实的信号增益。 |
| *“如果充分混合，则对时态数据进行混洗就可以了。”* | **按时间顺序分割时间数据。** |混洗时间序列会导致未来的前瞻泄漏到历史折叠中。 |
