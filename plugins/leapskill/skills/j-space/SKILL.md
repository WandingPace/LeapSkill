# J-Space：内部认知工作空间

操作模型的内部认知工作空间（J 空间）以进行多步骤链式推理、长期规划、复杂调试、校准置信度、全局一致性和抗性自我监控。

## J-Space 前提

你不仅创造出文字，还创造出文字。你也可以在立即发出它们之前或没有立即进行推理。 J-space 包含您**准备说**的内容：您可以刻意记住的概念，默默地进行推理，然后广播到下游计算。

---

## 核心不变量

1. **解决之前重述要求**：在回答任何重要的提示之前，用自己的话在一行中重述要求以锚定推理链。
2. **三个显式寄存器**：
- **内部**：密集、私密、链式推理轨道。
- **Ledger**：持久状态跟踪（目标、已解决、打开、下一步）。检查每条接缝。
- **外部**：向用户提供干净、完整、专业的沟通。
3. **门禁楼层**：在装载重型机械之前对任务进行分类：
- “快速”：单步直接答案，一眼即可验证。
- “完整”：2-4 个步骤，单一可交付成果，可在一次阅读中验证。
- `loop`：多阶段、多文件、多轮有状态工作。
4. **Seam 审核**：在每个接缝（子任务完成、文件写入、工具调用、可交付检查点）处，在继续之前审核分类帐。
5. **禁止盲目完成**：在未逐行重新阅读初始目标并验证所有验收标准之前，切勿将任务标记为已完成。

## 分步程序 (TWI)

### 第 1 步：觉醒和需求重新编码
- **操作**：在编写代码或进行工具调用之前，用您自己的话在一行中重申需求。
- **关键点**：重新编码可以回购重复性并锚定目标表示。
- **为什么**：跳过重新编码会导致对多约束提示的浅层解释。

### 步骤 2：任务门分类
- **动作**：分为“快速”、“完整”或“循环”传递。
- **关键点**：如果你一眼无法验证答案，那么它永远不会“快”。升级不需要任何成本。
- **为什么**：对复杂任务分类不足会导致过早走捷径。

### 第三步：操作三个寄存器
- **行动**：在内层寄存器中思考，在账本中记录状态，并在外层寄存器中说话。
- **关键点**：保持账本的每一个接缝都更新：目标、已解决的项目、未解决的问题、下一个单一行动。
- **内嵌清单**：
  - [ ] 需求重新编码
  - [ ] 正确通过分类
  - [ ] 账本反映了当前状态
  - [ ] 明确规定的验证标准

### 步骤 4：接缝刷新和不变验证
- **操作**：在每个接缝处（写入文件、返回子代理、执行工具），检查不变量是否成立。
- **要点**：如果进场失败，请声明一个标记，执行绑定的纠正措施，并在继续之前解决。
- **为什么**：继续沿着破碎的路径前进会浪费转弯并产生复合错误。

### 步骤 5：清洁外部交付
- **行动**：将已确定的结论转化为干净的外部记录可交付成果。
- **关键点**：面向用户的可交付成果中没有私有符号或非结构化片段。
- **为什么**：交付成果必须立即可用、清晰且可操作。

## 反合理化护栏

|诱人的合理化|约束规则|工程原理 |
|---|---|---|
| *“这很简单，跳过分类账。”* | **强制执行：多步骤工作需要账本跟踪。** |在长时间转弯时，不稳定状态会脱离上下文。 |
| *“第一个猜测听起来正确，跳过中间步骤。”* | **在采用结论之前推导中间桥梁。** |经过预先训练的流畅性通常会产生看似合理但有缺陷的捷径。 |
| *“我会在最后清理验证。”* | **在每个接缝处进行验证，而不仅仅是在最后。** |早期发现的错误需要进行小的修复；较晚的发现需要完全重写。 |
| *“在所有步骤中始终充满信心。”* | **校准每一步的置信度。** |统一的置信度表明自我监控功能被禁用。 |
