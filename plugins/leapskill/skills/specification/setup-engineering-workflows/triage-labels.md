# Triage 标签

skills 使用五个标准 triage 角色。这个文件把这些角色映射到当前仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当 skill 提到某个角色（例如“打上 AFK-ready triage 标签”）时，使用这张表中对应的标签字符串。

修改右列，让它匹配你们实际使用的词汇。
