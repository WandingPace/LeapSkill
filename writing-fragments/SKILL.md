# 书写片段

通过不断地将原始写作片段、引用、类比和主要隐喻提取到以分隔符分隔的 Markdown 笔记文件中，促进低压思想捕获和苏格拉底式探索。

---

## 核心不变量

1. **纯粹探索模式**：切勿强行过早构建结构、大纲或段落分组；保持捕获摩擦接近于零。
2. **水平规则分隔符**：在单个顶级“#工作标题”下使用水平规则（“---”）分隔每个不同的片段。
3. **连续磁盘重新读取**：在附加之前始终从磁盘重新读取目标片段 Markdown 文件，以保留人工带外编辑。
4. **引导词提取**：主动识别并创造锚定核心概念点的紧凑隐喻（“引导词”）。
5. **无开销元数据**：避免将目录、时间戳、作者前言或类别标签添加到原始片段文件中。

---

## 架构和内容地图 (MOC)

```
[ Freeform Ideation / Grilling Dialogue ] ──► [ Extract Raw Fragment / Leading Word ] ──► [ Append to `notes.md` via `---` ] ──► [ Re-read Before Next Write ]
```

|片段类型 |结构|目的|
|---|---|---|
| **尖锐的句子** |单打孔线 |可重复使用的挂钩或论文锚 |
| **小插曲/轶事** |简短的叙述段落|现实世界的混凝土接地 |
| **引述/对话** |带归属的块引用 |主要来源证据|
| **主导词** |创造的隐喻/术语|塑造未来的承重概念|

---

## 分步程序 (TWI)

### 步骤一：初始化工作文件及设定目标路径
- **操作**：询问用户一次目标文件路径（如果省略）并使用“#Working Title”进行初始化。
- **要点**：从用户的第一个提示开始立即捕获。
- **为什么**：零前期官僚主义可以最大限度地发挥创意动力。

### 第二步：苏格拉底式探索和片段提取
- **行动**：坚持不懈地采访用户，揭示非显而易见的观察结果、逆向观点和尖锐的表述。
- **要点**：当出现一个强大的重复主题时，创造一个紧凑的“主导词”（例如*曳光弹*、*战争迷雾*）。
- **内嵌清单**：
  - [ ] 片段严格用“---”分隔
  - [ ] 原始片段文件内没有内部副标题 (H2/H3)
  - [ ] 每次追加之前从磁盘重新读取文件

### 步骤 3：增量静默追加
- **操作**：将商定的片段附加到磁盘而不中断对话流。
- **为什么**：持续、无阻塞的持久性确保不会丢失转瞬即逝的想法。

## 反合理化护栏

|诱人的合理化|约束规则|工程原理 |
|---|---|---|
| *“将原始片段组织成编号的主题部分。”* | **禁止。保持原始片段非结构化。** |过早的组织会封闭新的角度并产生认知摩擦。 |
| *“用新组织的版本覆盖文件。”* | **仅附加；保留人工手动编辑。** |覆盖会破坏带外的人工措辞和编辑。 |
| *“在编写每个片段之前先征求许可。”* | **默默附加并顺便提及。** |持续的保存确认提示会破坏富有成效的头脑风暴流程。 |
